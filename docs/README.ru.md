# MSI EC для Omarchy / MSI Thin GF63 12VE

[English](../README.md) · [Точные изменения](CHANGES.md) · [Проверки](VALIDATION.md)

Пакет помогает в ситуации, когда штатный драйвер ядра не предоставляет
управление вентиляторами для EC `16R8IMS1.108`, а свежий исходник `msi-ec`
не собирается из-за переименования API батареи в ядре.

Поддержка этой EC-прошивки уже была в upstream. Здесь сохранены исходники
реально установленного варианта, две замены API, исправленная упаковка DKMS,
проверка совместимости и откат. **BIOS не прошивается. Приложение MControlCenter
не переписывалось и в пакет не входит.**

## Проверенная конфигурация

- MSI Thin GF63 12VE.
- BIOS `E16R8IMS.10E`.
- EC `16R8IMS1.108` — версия EC и версия BIOS являются разными значениями.
- Arch Linux / Omarchy 4, ядро `7.2.8-9-omarchy`.
- Работавший локальный пакет: `0.13-omarchy1`; версия упаковки в репозитории:
  `0.13-omarchy2`.
- MControlCenter `0.5.1`, штатные бинарники.

На другом BIOS, EC или ноутбуке установщик остановится. Даже одинаковое
название модели не гарантирует одинаковую прошивку контроллера.

## Установка

Распакуйте исходники из **Code → Download ZIP** либо клонируйте репозиторий.
Откройте терминал в его папке. Для клонирования:

```bash
git clone https://github.com/Mirox921/msi-ec-omarchy.git
cd msi-ec-omarchy
```

```bash
sudo pacman -S --needed base-devel dkms python
uname -r
```

Установите заголовки именно вашего ядра: `linux-headers` для `linux`,
`linux-lts-headers` для `linux-lts`, либо заголовки конкретного ядра Omarchy
из того же источника. Проверка ожидает `/lib/modules/$(uname -r)/build`.

```bash
python3 scripts/check_system.py
make
sudo bash scripts/install.sh
```

Если версия EC не видна, не угадывайте её. Порядок независимой проверки и
параметр подтверждения описаны в [INSTALL.md](INSTALL.md#when-the-ec-version-is-not-exposed).

После успешной установки перезагрузитесь. Проверка:

```bash
modinfo -n msi_ec
dkms status
cat /sys/devices/platform/msi-ec/fw_version
cat /sys/devices/platform/msi-ec/available_fan_modes
cat /sys/devices/platform/msi-ec/fan_mode
```

Установщик не выгружает работающий модуль, не перезаписывает BIOS, не задаёт
кривые и не копирует чужие настройки вентиляторов. Он устанавливает пакет DKMS
и отдельную запись автозагрузки. Сам драйвер активируется после перезагрузки.

Если `0.13-omarchy1` уже работает, менять его ради этой страницы не требуется.
Установщик откажется устанавливать второй пакет MSI EC поверх существующего.

## Интерфейс управления

MControlCenter устанавливается отдельно из его официального проекта или
пакета дистрибутива. В исходной настройке помимо драйвера задавались
индивидуальные кривые и автозапуск приложения. Эти настройки не публикуются
как универсальные: перенос чужих значений регистров EC небезопасен.

Начните со штатного автоматического режима и проверьте поведение температур
и вентиляторов. При аномалиях прекратите изменение режимов. Не используйте
принудительный профиль прошивки.

## Откат

Закройте MControlCenter и отключите созданный вами автозапуск расширенного
режима. Затем:

```bash
sudo bash scripts/uninstall.sh
```

Проверьте вывод DKMS о восстановлении оригинального модуля и перезагрузитесь.
Если оригинальный модуль не был сохранён DKMS, сначала переустановите пакет
вашего ядра и его заголовки. Скрипт удаляет только версию `0.13-omarchy2`,
не трогая другие пакеты DKMS и пользовательские настройки.

Сборка новой упаковки и проверка исходников не равны проверке охлаждения на
другом ноутбуке. Полный статус тестирования указан в [VALIDATION.md](VALIDATION.md).
